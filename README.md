# 🎯 QuizMaster App

QuizMaster adalah aplikasi kuis interaktif berbasis **React JS**.  
Aplikasi ini mengambil soal secara real-time dari Open Trivia DB API dan mendukung fitur **login, timer, progress, result, serta resume quiz menggunakan localStorage**.

---

## 🚀 Demo Features

✅ Login user  
✅ Fetch soal dari API (Open Trivia DB)  
✅ 1 soal per halaman  
✅ Pilih jawaban → otomatis lanjut  
✅ Timer countdown  
✅ Auto submit saat waktu habis  
✅ Progress bar  
✅ Halaman hasil lengkap (skor, benar, salah, review)  
✅ Resume quiz saat browser ditutup (localStorage) ⭐  

---

## 🖥️ Tech Stack

- React (Hooks)
- React Router
- Tailwind CSS
- Framer Motion (animation)
- Lucide React (icons)
- LocalStorage (session persistence)
- Open Trivia DB API (https://opentdb.com/)
